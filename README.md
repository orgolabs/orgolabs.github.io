# orgolabs.github.io

The landing page for **[orgolabs](https://github.com/orgolabs)** — interactive, fact-checked organic
chemistry labs. Live at **https://orgolabs.github.io/**.

A self-contained static page with its own identity (serif display + grotesque body, "chalkboard chemistry"
palette, molecular line-art motif). It links to each lab and pulls the shared brand mark from
`orgolabs.github.io/shared`. Content & code MIT-licensed.
